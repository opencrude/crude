# Rules of thumb when updating:
#   - Tighten when a fix lands (set to measured + ~20% headroom).
#   - Loosen only with a PR note explaining the new cost, and verify on a quiet

#   - Leaf benches catch a function getting fatter. Scenario benches
#     (IdleTick/TabRederive, gated on tui/perf work counters in tests) catch
#     call-frequency regressions — a dropped per-tick cache shows up in the
#     work-budget tests and as a multi-x alloc jump here, not as a leaf change.
